How I work

01

Use it before writing it

I run the setup myself and write down where I got stuck. A page written from a spec reads like a spec; a page written from the work reads like help.

02

One task per page

Titles name the job, not the feature. If a topic needs the word "and" in its title, it's two topics sharing one URL.

03

Watch someone follow it

Someone who's never seen the product works through the steps while I stay quiet. Every hesitation is an edit or a deletion.
