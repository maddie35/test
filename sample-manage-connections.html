Sample 05 · task-based help topic

Manage connections

This document covers how to manage your friend connections in the TransTech Summit App.

Table of contents

  • Add a connection
  • Remove a connection
  • Block a connection
  • Accept a connection request
  • Still need help?

Add a connection

On a computer

  1. 01Access the Summit App from a web browser.Note: for a better experience, we recommend using Google Chrome.
  2. 02Select Home > Attendees in the left-hand menu.
  3. 03In the list of attendees, locate the person you want to connect with.
  4. 04Click Add.

Summit App · web

On the mobile app

  1. 01Open the Summit App on your mobile device.
  2. 02Tap the Attendees icon on the Home page.
  3. 03In the list of attendees, find the person you want to connect with.
  4. 04Tap the Add button next to their name.

Summit App · mobile

Remove a connection

At this time, you can only remove connections from a web browser.

  1. 01Access the Summit App from a web browser.Note: for a better experience, we recommend using Google Chrome.
  2. 02Click Connections on the left menu.
  3. 03Click the person's name to open their profile.

Step 3

  1. 04In the top right-hand corner of the page, click the trash bin icon.

Step 4

  1. 05Click Yes in the confirmation pop-up.

Step 5

Block a connection

At this time, you can only block connections from the mobile app, not from a computer. Also, you can only block users who are your connections.

  1. 01In the mobile app, tap Connections.
  2. 02Tap the person's name to open their profile.

Steps 1–2

  1. 03At the bottom of the page, tap Block Connection.

Step 3

Accept a connection request

On a computer

  1. 01Access the Summit App from a web browser.Note: for a better experience, we recommend using Google Chrome.
  2. 02Click Connections in the left menu.
  3. 03Click the bell icon in the top toolbar.
  4. 04In the popup, click the check box next to the user's name.

Summit App · web

On the mobile app

  1. 01Tap Connections.
  2. 02Tap the bell icon in the top right.

Steps 1–2

  1. 03Tap the Add button next to the user's name.

Step 3

Still need help?

For additional help, here's how you can reach out to us:

  • 01Discord, in the transtech-summit-help-desk channel.
  • 02The Live Help Desk in the Summit App or website.
